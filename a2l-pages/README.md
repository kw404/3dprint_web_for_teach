# A2L 切片教室：GitHub Pages 版

這是純靜態網站；STL、切片運算、預覽及 ZIP 封裝均在學生瀏覽器執行，不需要 Python、Bambu Studio 或切片伺服器。模型不會上傳。需透過 HTTPS 或 localhost 開啟，不能直接雙擊 index.html。

## 自行發布（不必執行建置）

1. 解壓縮網站包，把 a2l-pages **資料夾內的內容**放到 GitHub repository 根目錄，確認根目錄有 index.html、app.js、vendor 等。
2. GitHub repository → Settings → Pages → Source 選 Deploy from a branch。
3. Branch 選 main、資料夾選 / (root)，儲存。發布完成後把 GitHub 提供的網址給學生。
4. 亦可選 GitHub Actions 作為 Source，使用隨附的 .github/workflows/pages.yml；上述兩種方式擇一。

不需要設定 API 網址或金鑰。所有資源使用相對路徑，可部署在帳號首頁或 /repository/ 子路徑。

## 已完成與限制

### 2026-10-19：選面貼底、懸空提醒與可編輯專案

- 按「選面貼底」，再點模型的外側平面：黃色為選取提示，該面會朝下，整個模型移到 Z=0。凹槽內側面不一定能接觸底板，請優先選外側平面。Esc 取消；旋轉後需重新切片。
- 匯入、旋轉或縮放後檢查離開底板且超過 45° 的朝下表面。這是「可能懸空」提醒，橋接、下方已有模型或非封閉網格可能造成誤判；啟用支撐不代表已覆蓋所有懸空區，仍需逐層檢查。
- 「儲存專案 .3mf」不需先切片，保存原始網格、方向、尺寸、位置及網站支援的列印參數。使用「新增模型」重新開啟可續編；不會保存生成的支撐網格或切片預覽，下次需重新切片。
- Bambu Studio 請使用「開啟專案」讀取此 3MF，可調整模型與列印設定；無法還原原始 CAD 建模歷程。網頁僅能讀回本網站儲存的專案，不能讀回任意 Bambu Studio 編輯後另存的 3MF。
- 與「匯出 A2L 測試檔」產生的 .gcode.3mf 分開：後者主要是已切片列印輸出。
- 使用提供的 IKEA STL 驗證懸空提醒、選面後尺寸 170×89.7×30 mm，以及瀏覽器專案儲存／重新開啟。Bambu Studio 02.08.02.61 原生引擎亦讀入該模型與 0.16 mm／支撐設定並完成重新切片；尚未實機列印。

既有 GitHub Pages 更新：把更新包內所有檔案放進原本 `a2l-pages 2` 資料夾並取代同名檔案；新增的 project.js 與 geometry-check.js 也必須上傳。網址不需變更。重新整理載入新版本。

- STL 匯入、旋轉、縮放、置中；固定 A2L、0.4 mm、Generic PLA、紋理 PEI。
- Web Worker + WebAssembly 真實切片，支援取消、層高、牆壁、填充、支撐及外側裙邊。
- 圓角截面的線材預覽；灰綠為模型、灰褐為支撐，依引擎數值角色匹配，不能由 unsupported 等文字推測。
- 產生含 G-code 的 .gcode.3mf；固定機器啟動／結束程序由本機官方 A2L 設定衍生。
- **這是 A2L 輸出測試版，尚未完成實機列印與所有 3MF 消費端相容性驗證。不是完整 Bambu Studio；路徑、支撐策略和估時可能不同。不能宣稱已驗證可直接交給全班列印。**
- 某些細小模型及層高／支撐組合仍會產生空層；遇到空層或超界會停止匯出。估時不含完整機器準備動作。
- 模型高度限制 324.5 mm，預留結束抬升；最大 300,000 三角形／20 MB。
- 支撐分類已以 101.stl 測試：關閉支撐時 16,444 段全部為模型；開啟支撐時 5,233 段為支撐，16,444 段仍為模型。
- 已在純靜態子路徑測試方塊 100 層與 101.stl 638 層；沒有呼叫本機切片 API。

原先由 Bambu Studio 原生引擎切片的版本另保留，兩者不是同一個切片引擎。

### 斜面與面板收合

選面貼底支援外側斜面：點選後，以該面的法線旋轉整個模型，再將模型最低點放到列印板。凹槽內側面或曲面上的小三角形不一定是合適的接觸面。切片結果與懸空警告標題右側可收合／展開，收合僅隱藏內容，不會關閉檢查或刪除結果。

### 2026-10-19：跨邊緣貼底與輪廓修正

- 選面貼底現在先列出模型凸包的主要候選平面，包含跨越兩條邊、盒口的虛擬平面。切換選單查看黃色預覽，按套用後才旋轉；仍可切換直接選面。黃色區域不是新增的模型材料，也不表示整個區域都會接觸底板。
- 修正原核心以 0.001 mm XY 桶連接輪廓、斷鏈後直接封口造成的假斜面。現在先以共享網格邊連接截面，再交給同一核心產生牆壁、填充與 G-code；斷鏈或分岔即停止輸出。網格重疊、自交與非流形模型不在本次完整驗證範圍。
- 回歸：IKEA 模型原錯誤方向 193 層，上部跨空腔的長斜線移除；方塊 100 層、101.stl 638 層通過。實機列印仍未驗證。
- 新增 bed-planes.js、topology-slice.js、vendor/ConvexHull.js；最後一項取自 Three.js r180 官方來源，沿用 vendor/LICENSE.txt 的 MIT 授權。

末端沒有擠出路徑的空尾層會移除；中間空層仍阻止匯出。本次精確候選平面案例移除一個空尾層後為 193 層。凸包僅提供幾何候選，不保證支撐充足或實際黏附穩定。
